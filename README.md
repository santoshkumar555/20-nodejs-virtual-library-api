# Secure Virtual Library API (MEN Stack)

A secure MEN Stack REST API for managing a virtual library — featuring JWT auth with OTP login, 
bcrypt password hashing, author-book relationships via MongoDB ObjectIds, and Multer-powered 
image uploads with automatic cleanup on deletion.

Live Demo: [View Here](https://nodejs-virtual-library-api.onrender.com/)

Postman Collection: Import the collection from `docs/postman/virtual-library-api.postman.json` to test all endpoints in Postman.
